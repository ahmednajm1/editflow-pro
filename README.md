# EditFlow Pro

AI-powered Adobe Premiere Pro CEP Extension by **Najm Media**.

Auto-transcribe any language and place perfectly timed, animated captions on your timeline — powered by Whisper AI.

## Install
```bash
bash <(curl -sSL https://github.com/ahmednajm1/editflow-pro/releases/latest/download/install.sh)
```

## Features
- 🔊 Audio Level nudge controls
- 🖼️ Static Scale presets
- 📐 Transform & Tools
- 🎬 AI Captions (15+ languages, animated styles)
- 📤 Export Engine
